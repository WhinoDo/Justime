#### 1.1 数据库查询优化

**问题 #1: N+1查询问题**
- **位置：** `app/business/chat_business.py`
- **问题：** 循环中执行数据库查询
- **影响：** 性能随数据量线性下降
- **优化方案：**
  ```python
  # 优化前
  conversations = await Conversation.find().to_list()
  for conv in conversations:
      messages = await Message.find({"conversation_id": conv.id}).to_list()

  # 优化后
  conversations = await Conversation.find().to_list()
  conv_ids = [c.id for c in conversations]
  all_messages = await Message.find(
      {"conversation_id": {"$in": conv_ids}}
  ).to_list()
  
  # 构建映射
  messages_by_conv = defaultdict(list)
  for msg in all_messages:
      messages_by_conv[msg.conversation_id].append(msg)
  ```

**问题 #3: 频繁查询未缓存**
- **影响：** 数据库压力大，响应时间长
- **优化方案：**
  ```python
  # 使用Redis缓存
  from functools import lru_cache
  import redis
  import json

  class CacheService:
      def __init__(self):
          self.redis = redis.Redis(host='localhost', port=6379, db=0)

      async def get_user_config(self, user_id: str):
          cache_key = f"user_config:{user_id}"
          cached = self.redis.get(cache_key)
          
          if cached:
              return json.loads(cached)
          
          # 从数据库获取
          config = await UserConfig.find_one({"user_id": user_id})
          
          # 缓存1小时
          self.redis.setex(cache_key, 3600, json.dumps(config))
          return config
  ```

- **位置：** `app/api/v1/endpoints/knowledge.py:81`

- **优化方案：**

  ```python
  import aiofiles

  async def save_file_streaming(file: UploadFile, path: str):
      """流式保存文件"""
      async with aiofiles.open(path, 'wb') as f:
          while chunk := await file.read(1024 * 1024):  # 1MB chunks
              await f.write(chunk)
              
              # 检查文件大小限制
              current_size = await f.seek(0, 2)  # 获取当前大小
              if current_size > MAX_FILE_SIZE:
                  await f.close()
                  os.remove(path)
                  raise HTTPException(413, "File too large")
  ```

#### 1.4 异步处理优化

**问题 #5: 知识库索引重建阻塞请求**
- **位置：** `app/api/v1/endpoints/knowledge.py:208`
- **影响：** 请求超时，用户体验差
- **优化方案：**
  ```python
  from fastapi import BackgroundTasks
  from uuid import uuid4

  # 任务状态存储
  rebuild_tasks = {}

  async def rebuild_index_task(task_id: str, kb_id: str):
      rebuild_tasks[task_id] = {"status": "running", "progress": 0}
      try:
          # 执行重建
          await knowledge_service.rebuild_index(kb_id)
          rebuild_tasks[task_id] = {"status": "completed", "progress": 100}
      except Exception as e:
          rebuild_tasks[task_id] = {"status": "failed", "error": str(e)}

  @router.post("/knowledge/{kb_id}/rebuild")
  async def rebuild_knowledge_index(
      kb_id: str,
      background_tasks: BackgroundTasks
  ):
      task_id = str(uuid4())
      background_tasks.add_task(rebuild_index_task, task_id, kb_id)
      return {"task_id": task_id, "status": "pending"}

  @router.get("/knowledge/rebuild/{task_id}")
  async def get_rebuild_status(task_id: str):
      return rebuild_tasks.get(task_id, {"status": "not_found"})
  ```

  ```python
  class MessageInput(BaseModel):
  ```

  ```python
  import logging

  class SensitiveDataFilter(logging.Filter):
      SENSITIVE_FIELDS = ['password', 'token', 'api_key', 'secret']
      
      def filter(self, record):
          msg = record.getMessage()
          for field in self.SENSITIVE_FIELDS:
              msg = re.sub(
                  f'{field}=[^\\s]+',
                  f'{field}=***',
                  msg
              )
          record.msg = msg
          return True

  logging.getLogger().addFilter(SensitiveDataFilter())
  ```

### 4. 可维护性优化

#### 4.1 依赖注入

**问题 #12: 硬编码依赖**
- **影响：** 测试困难，耦合度高
- **优化方案：**
  ```python
  from typing import Protocol

  # 定义接口
  class ICacheService(Protocol):
      async def get(self, key: str) -> Any: ...
      async def set(self, key: str, value: Any) -> None: ...

  # 实现类
  class RedisCacheService:
      def __init__(self, redis_client: Redis):
          self.redis = redis_client

      async def get(self, key: str) -> Any:
          return await self.redis.get(key)

  # 依赖注入
  class UserService:
      def __init__(self, cache: ICacheService):
          self.cache = cache

  # 工厂函数
  def create_user_service() -> UserService:
      cache = RedisCacheService(get_redis_client())
      return UserService(cache)
  ```
