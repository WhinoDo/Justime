# 💡 飞书日历集成配置指引 (Lark Calendar Configuration)

本文档将指导您如何在 **飞书开放平台** 创建自建应用，获取 `App ID` (Key) 和 `App Secret`，并在 **矩时 (Justime)** 平台中无缝映射您的飞书日历。

---

## 📅 快速配置五步法

### 第一步：在飞书开放平台创建应用
1. 访问 [飞书开放平台官网 (open.feishu.cn)](https://open.feishu.cn) 并使用您的企业/个人账号登录。
2. 点击右上角的 **“控制台”**。
3. 在控制台首页，点击 **“创建企业自建应用”**。
4. 填写基本信息：
   - **应用名称**：`矩时日程助手` (或任意名称)
   - **应用描述**：`用于映射并双向同步矩时 AI 智能日程`
   - **应用图标**：可选择上传矩时官方图标。
5. 点击 **“确定创建”**。

---

### 第二步：申请开放日历核心权限
在左侧导航栏中，点击 **“开发配置”** -> **“权限管理”**，在搜索框中搜索并勾选开通以下 **两项核心日历权限**：
1. 🔍 **获取日历信息** (`calendar:calendar`)
   - *说明：用于查询日历列表以及获取特定日历的基础属性*
2. ✍️ **获取、写入日程信息** (`calendar:calendar.event`)
   - *说明：用于日程的创建 (Create)、详情拉取 (Read)、局部更新 (Update) 以及物理删除 (Delete)*

> [!IMPORTANT]  
> 勾选完毕后，如果您是**企业创建者/管理员**，可以直接在页面上方点击 **“一键审核/开通”**；如果您是企业普通成员，需提交审核并在飞书客户端内由企业管理员批准。

---

### 第三步：获取应用密钥凭证 (Key & Secret)
1. 点击左侧导航栏的 **“开发配置”** -> **“凭证与基础信息”**。
2. 在 **“应用凭证”** 区域，您将看到您的应用身份标识：
   - 🔑 **App ID** (即飞书 Key，格式如 `cli_a1b2c3d4e5f6g7h8`)
   - 🔒 **App Secret** (即飞书 Secret，点击眼睛图标显示，请妥善保管)
3. 点击右侧复制按钮，将这两个字段备用。

---

### 第四步：完成应用版本发布 (使权限在租户内生效)
飞书要求应用必须发布版本，所申请的权限才会在企业内正式生效：
1. 点击左侧导航栏 **“应用发布”** -> **「版本创建与发布」**。
2. 点击 **“创建版本”**，填写版本号（例如 `1.0.0`），并输入简要更新说明（例如：`开启日历映射集成`）。
3. 点击保存并 **“申请发布”**。对于企业自建应用，发布申请一般会自动批准生效。

---

### 第五步：在后端的 `.env` 配置文件中注入生效
1. 打开项目后端目录下的配置文件 `justime_backend/.env`。
2. 将您获取到的应用密钥填入其中，并启用飞书集成开关：
   ```bash
   # 1. 开启飞书映射集成
   FEISHU_INTEGRATION_ENABLED=true

   # 2. 填写您的飞书应用凭证
   FEISHU_APP_ID=您的_App_ID_cli_xxxxxx
   FEISHU_APP_SECRET=您的_App_Secret_xxxxxx
   ```
3. 在终端中，使用项目虚拟环境运行集成 CLI 小助手，快速初始化专属日历：
   ```bash
   # 在项目根目录下，利用后端虚拟环境的 python 运行：
   python3 scripts/feishu_cli.py init-calendar
   ```
   - 脚本会自动为您在飞书上建立名为 **“矩时 (Justime) 智能日程表”** 的专属日历，并输出其唯一的 `Calendar ID`。
4. 将生成的 `Calendar ID` 追加填入您的 `.env` 中：
   ```bash
   FEISHU_CALENDAR_ID=专属日历_ID_xxxxxx
   ```
5. 保存 `.env` 并重启您的后端服务 (`python start.py`)。大功告成！

---

## 🛡️ 安全注意事项
> [!WARNING]  
> **App Secret 包含您飞书企业组织的全部日历访问权限**，请绝对不要将其提交到任何公共代码仓库 (如 GitHub)。
> 
> 后端服务已经对 Token 实现了 **Redis 缓存保护**，每一次向飞书请求的 Token 都会在内部进行秒级加密缓存，极大地降低了泄露风险，并提升了接口响应性能。
