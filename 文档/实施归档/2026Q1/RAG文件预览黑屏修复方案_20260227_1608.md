# RAG 文件预览无法正确显示（只有模糊背景）问题修复方案

## 🐛 问题原因分析

目前，点击聊天中 AI 引用回答下的文档名称时，管理后台的整个界面会变成灰暗模糊的背景，且无法看到任何文件预览卡片。

引发此问题的根源在于 `src/components/chat/ChatInterface.tsx` 中的响应式渲染冲突，以及 `src/components/ui/dialog.tsx` 组件缺少自定义样式穿透能力：

1. **响应式逻辑重叠**：桌面端和移动端共享相同的 `previewOpen` 状态。桌面版中，右侧划出一个固定宽度的 `RagReferencePreviewPanel`。但在移动端设计中，它被包在一个全屏居中的 `<Dialog>` 里。
2. **隐藏逻辑不完整**：为了在桌面端隐藏移动版的 `<Dialog>`，代码中只在 `<DialogContent>` 加了 `md:hidden`，但这**只能隐藏对话框的内容体，无法隐藏全屏的暗色模糊遮罩 (`DialogOverlay`)**。
3. **导致的结果**：在桌面端一点击预览，右侧弹出了正常的预览面板，但此时 `<Dialog>` 的全屏灰暗磨砂遮罩也跟着弹出了，彻底遮挡/模糊了整个界面，导致你看不到任何东西。

---

## 🛠️ 给 Codex 的修复要求

请遵循以下两步修改，彻底解决背景遮挡的问题：

### 第一步：让 `Dialog` 组件支持 `className`，以便用 CSS 隐藏它本身及遮罩
在 `justime_agent/src/components/ui/dialog.tsx` 中：
1. 为 `DialogProps` 增加 `className?: string`。
2. 将 `<Dialog>` 根容器 `div` 改为使用 `cn()` 拼接。

具体修改内容：
```tsx
import { cn } from "@/lib/utils"

interface DialogProps {
  open?: boolean
  onOpenChange?: (open: boolean) => void
  children: React.ReactNode
  className?: string // ✅ 1. 新增 className
}

const Dialog: React.FC<DialogProps> = ({ open, onOpenChange, children, className }) => {
  // ... 此前代码不变 ...
  
  if (!open) return null

  return (
    // ✅ 2. 注入传入的 className
    <div className={cn("fixed inset-0 z-50 flex items-center justify-center", className)}>
      {/* Overlay */}
      <div
        className="fixed inset-0 bg-black/50 backdrop-blur-sm"
        onClick={() => onOpenChange?.(false)}
      />
      {/* Content */}
      <div className="relative z-50">
        {children}
      </div>
    </div>
  )
}
```

### 第二步：在 `ChatInterface.tsx` 为外部 `<Dialog>` 层级增加 `md:hidden`

在 `justime_agent/src/components/chat/ChatInterface.tsx` 中，找到文件底部的 `<Dialog>` 代码（大约在 1081 行），进行修改：

```tsx
      {/* ✅ 1. 给 Dialog 把 md:hidden 加上，这样它的深色遮罩在桌面端也会彻底消失 */}
      <Dialog 
         open={previewOpen && !!selectedReference} 
         onOpenChange={setPreviewOpen} 
         className="md:hidden" 
      >
        {/* ✅ 2. 把这里的 md:hidden 去掉（因为父级已经 hidden 了，子级不用加了） */}
        <DialogContent className="w-[95vw] max-w-none h-[82vh] p-0">
          <RagReferencePreviewPanel
            open={previewOpen}
            reference={selectedReference}
            activeTab={activeTab}
            onTabChange={setActiveTab}
            fullContentState={selectedFullContent}
            isFullContentLoading={isFullContentLoading}
            onClose={() => setPreviewOpen(false)}
            className="h-full"
          />
        </DialogContent>
      </Dialog>
```

只要改完这两处，就能完美实现桌面侧边滑出面板、移动端底部全覆盖的丝滑 RAG 预览体验，快出发吧！
