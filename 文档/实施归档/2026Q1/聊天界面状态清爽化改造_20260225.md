# 自适应UI优化方案记录

## 时间与背景
**日期**: 2026-02-25
**背景**: 用户提出，在系统进行普通对话时，界面不应该展示过多的分析信息（由于任务分类器会持续判断任务类型，导致每次对话气泡上方都出现一排包含 `通用任务`、`难度 1`、`低紧急` 等字眼的面包屑标签），显得冗杂。这些意图分析组件只有在确实需要复杂系统运转、日程分析、或者拆解计划时才对用户有感知意义。

## 涉及文件
- 路径: `justime_agent/src/components/chat/MessageBubble.tsx`

## 修改内容
我们在 `MessageBubble.tsx` 内关于任务分析元数据（Task Analysis Metadata）渲染的层级上加入了拦截逻辑：
原有的显示条件仅判断后端是否下发了 `taskAnalysis` 数据：
```tsx
{(message.timingStrategy || message.taskAnalysis) && ( ... ) }
```

**修改后的逻辑增加了排除普通任务（General Task）判断**：
```tsx
{(message.timingStrategy || message.taskAnalysis) && 
 (message.taskAnalysis?.taskType !== 'general' && message.timingStrategy?.taskType !== 'general') && (
 ...
)}
```

## 效果
1. 所有的随口闲聊（例如打招呼、简单提问）等被模型判定为 `taskType: general` 的消息中，气泡上方的**意图、难度与紧急程度标签将被完全隐藏**。整个聊天界面观感更为干净整洁。
2. 当用户抛出复杂任务需要智能拆解，或是带有时间意图需要安排日程时，后台判定为 `thinking` 或其他非 `general` 类型，**分析组件又会随之自动出现**，辅助交代 AI 后台运转的分析维度与置信度，呈现更专业的 Agent 面貌。
