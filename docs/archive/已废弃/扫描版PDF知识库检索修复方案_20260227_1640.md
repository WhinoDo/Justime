# 扫描版/纯图片 PDF 无法检索的问题分析与修复方案

## 🐛 问题原因分析
经过在后端的深度代码测试，我已经明确定位到了 PDF（具体是 `串.pdf`）无法被检索的原因：
该 PDF 本质上是一个**扫描件**（或者是纯图片的幻灯片导出），每一页只有图片，没有任何可供提取的底层文字流。
当现有代码使用 LlamaIndex 默认的提取器（`pypdf`）去解析它时，最终提取出的文本长度为 `0`。由于存入向量检索库 RAG 里的内容是空的，无论是查看预览内容，还是进行知识检索，自然什么都出不来。

---

## 🛠️ 给 Codex 的终极修复方案

要彻底解决扫描件 PDF 知识库的盲区，我们需要赋予后端 OCR（光学字符识别）的视觉能力。请让 Codex 按照以下三步进行改造：

### 第一步：引入图像与 OCR 处理依赖库
修改 `justime_backend/requirements.txt`，追加以下依赖：
```text
PyMuPDF>=1.23.0
pytesseract>=0.3.10
Pillow>=10.0.0
```
> **💡 环境提示**：由于 `pytesseract` 依赖于操作系统的 Tesseract 引擎，如果之前没有装过，还需要在终端执行一下 `brew install tesseract tesseract-lang`（Mac环境）。

### 第二步：在 `rag_service.py` 中编写带 OCR 兜底策略的自定义 Reader
在 `justime_backend/app/services/rag_service.py` 顶部或者合适的地方，创建一个具备**“常规抓取失败时能自动切入提取图片字”**的混合解析器：

```python
import fitz  # PyMuPDF
import pytesseract
from PIL import Image
from io import BytesIO
from pathlib import Path
from llama_index.core.readers.base import BaseReader
from llama_index.core.schema import Document

class OcrFallbackPDFReader(BaseReader):
    """支持图文 OCR 智能兜底的 PDF 大陆读取器"""
    
    def load_data(self, file_path, extra_info=None):
        if isinstance(file_path, str):
            file_path = Path(file_path)
            
        doc = fitz.open(str(file_path))
        text_parts = []
        
        for i in range(len(doc)):
            page = doc[i]
            # 1. 尝试常规的高速文本提取
            page_text = page.get_text().strip()
            
            # 2. 如果这页字太少（一般代表这是纯图/扫描页），则激活 OCR 引擎强行截取
            if len(page_text) < 15:  
                # 以 200 dpi 也就是高清模式截图该页
                pix = page.get_pixmap(dpi=200)
                img = Image.open(BytesIO(pix.tobytes("png")))
                
                try:
                    # 激活 tesseract 解析中英双语
                    # 注意：如果运行时报错找不到语言包，可暂时去掉 lang 参数
                    ocr_text = pytesseract.image_to_string(img, lang="chi_sim+eng").strip()
                    page_text = ocr_text
                except Exception as e:
                    print(f"⚠️ 第 {i} 页 OCR 提取失败: {e}")
                    
            if page_text:
                text_parts.append(f"--- 第 {i+1} 页 ---\n{page_text}")
                
        full_text = "\n\n".join(text_parts)
        metadata = extra_info or {}
        metadata.update({
            "file_name": file_path.name,
            "file_path": str(file_path)
        })
        
        return [Document(text=full_text, metadata=metadata)]
```

### 第三步：让 LlamaIndex 全局接管 PDF 解析任务
在 `justime_backend/app/services/rag_service.py` 内部的 `rebuild_index(self)` 方法里，将该自定义 Reader 装配到 `SimpleDirectoryReader` 中：
