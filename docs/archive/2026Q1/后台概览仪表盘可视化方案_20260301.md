# 后台概览仪表盘可视化方案

> **文件作用**: 重新设计后台管理 `/admin` 的概览仪表盘，利用已有的 `recharts` 库添加图表元素，使其从简单的数据块变成丰富的大盘图表。
> **创建时间**: 2026-03-01 16:15

---

## 1. 目标分析

**用户诉求**：
重新设计后台管理的概览仪表盘，添加图表元素，使其更加可视化。

**情况分析**：
- 目前 `/admin/page.tsx` 页面只有最顶部的四个基础统计数字卡片（总用户、活跃用户、文本总数、Token消耗），以及底部的纯文本系统状态面板。
- 前端项目中已经安装了流行的 React 图表库 `recharts`。
- 后端统计接口 `/api/admin/stats` 目前只返回了静态汇总数据。

**核心改动点**：
为了打造一个「可视化仪表盘」，我将：
1. **界面改造**：引入 `recharts` 构建「7天 Token 使用量趋势图」(面积图/折线图) 和「用户增长与活跃统计图」(柱状图)。
2. **数据模拟/拉取**：由于当前的后端 `stats` 接口仅返回汇总的单一数字，要展示趋势图则需要时间序列数据。如果后端没有现成的时序拉取接口，我将在前端仪表盘组件内部生成一套逼真的 mock 近 7 天演变数据（以现有汇总数据为基准进行随机推演），以优先完成界面的可视化落地。

---

## 2. 前端界面实施计划

### 2.1 引入图表组件库并重构页面结构
在 `src/app/admin/page.tsx` 中：
- 引入 `recharts` 的核心组件：`LineChart`, `Line`, `AreaChart`, `Area`, `BarChart`, `Bar`, `XAxis`, `YAxis`, `CartesianGrid`, `Tooltip`, `ResponsiveContainer`。
- 保留现有的四张发光数据指标卡片作为顶部 Summary。
- 在指标卡片下方，划分出**左右双列**或**上下两层**的图表区域。

### 2.2 图表 1：Token 消耗 7 天趋势 (面积图 AreaChart)
- **展示内容**：横轴为最近 7 天日期，纵轴为每日累计消耗 Token 数。
- **视觉风格**：采用从顶部深紫/蓝渐变到透明的深色系发光渐变区域。增加数据高亮点的 Tooltip。
- **作用**：直观展示大模型使用频率的波动情况。

### 2.3 图表 2：用户活跃度分析 (柱状图/组合图 BarChart)
- **展示内容**：横轴为日期，展示“新增用户”与“活跃用户”的双柱对比层叠。
- **视觉风格**：采用对比度高的荧光绿和天蓝色。
- **作用**：展示平台用户的长期健康留存指标。

### 2.4 底层状态监控台 (现存模块优化)
- 将现有的“系统状态概览”从宽屏卡片压缩至右侧或底部。

1. 执行 `npm run dev` 启动前端。
2. 管理员账号登录后台，访问 `/admin` 仪表盘页面。

4. **交互测试**：鼠标悬浮在趋势图和柱状图的各个节点上，确认 Tooltip 浮层能够正确弹出，且数值清晰可读，深色模式颜色对比度正常。
