# 矩时移动端 (React Native) - 聊天页面动态模型选择重构方案

## 1. 改造目标
目前 Web 前端已经实现了“动态模型管理与选择器”，用户可以在前端选择特定模型进行对话（例如 DeepSeek、GPT-4 等），而后端 `chat` 接口也已支持接收 `targetModelId`。
但移动端（`justime_mobile/app/(tabs)/index.tsx`）目前只传递了 `message` 和 `useWebSearch`，模型选择**完全处于写死/兜底状态**。

本方案旨在指导 `GPT-Codex3` 在移动端聊天页面顶部（或输入框上方）实现与 Web 端对齐的**「模型弹窗选择器」**。

---

## 2. 状态与接口准备

**目标文件：** `justime_mobile/app/(tabs)/index.tsx` 以及可能新增的 API 获取逻辑。

### 2.1 增加状态管理
在 `ChatScreen` 组件内新增模型相关的状态变量：
```tsx
const [availableModels, setAvailableModels] = useState<any[]>([]); // 存储从后端拉取的可用模型列表
const [selectedModelId, setSelectedModelId] = useState<string | null>(null); // 当前选中的模型
const [isModelPickerVisible, setModelPickerVisible] = useState(false); // 控制模型选择弹窗/底部的展示
```

### 2.2 获取可用模型列表
在原有的 `useEffect` 或专门创建一个加载模型的函数 `loadModels`：
- **API 端点**：使用现成的 `GET /api/v1/user/models`（或者如果 Web 端用的是 auth 下的公开路由，请对齐 URL，例如 `/api/auth/llm-configs` 的原生后端对应地址）。
- 由于移动端的 `baseUrl` 是动态的，必须携带 `Authorization: Bearer ${token}` 进行安全获取。

如果加载成功，更新 `availableModels`，并且如果 `selectedModelId` 为空，则自动将其设置为列表中的默认模型（如有 `is_default` 标记的，或列表的第一个）。

### 2.3 修改发信逻辑 (`handleSend` 函数)
定位到 `handleSend` 中调用 `fetch('${baseUrl}/api/v1/chat/', ...)` 的地方。
在 `body: JSON.stringify({...})` 中，补充 `targetModelId` 参数：
```tsx
body: JSON.stringify({
  message: content,
  sessionId,
  useWebSearch: useWebSearch,
  targetModelId: selectedModelId, // <--- 新增此字段
}),
```

## 3. 界面交互适配 (UI Implementation)

由于在手机屏幕上放一个巨大的下拉框体验不好，建议在页面顶部（Header）原来的副标题处（“• 在线”部分）做一个可点击的**胶囊按钮**，点击后从底部弹出一个 `<Modal>`（Bottom Sheet）供用户选择模型。

### 3.1 改造顶部 Header
**原代码：**
```tsx
<View style={styles.headerLeft}>
  {/* 历史记录按钮 */}
  <View>
    <ThemedText type="heading">{headerTitle}</ThemedText>
    <ThemedText type="caption" style={{ color: Colors.light.success }}>• 在线</ThemedText>
  </View>
</View>
```

**改造后思路：**
将 “• 在线” 替换为一个动态模型选择按钮：
```tsx
<TouchableOpacity 
  style={styles.modelSelectBadge} 
  onPress={() => setModelPickerVisible(true)}
>
  <ThemedText type="caption" style={{ color: Colors.light.primary }}>
    {availableModels.find(m => m.id === selectedModelId)?.name || '默认模型'}
  </ThemedText>
  <IconSymbol name="chevron.down" size={12} color={Colors.light.primary} />
</TouchableOpacity>
```

### 3.2 实现底部弹出选择器 (Modal Bottom Sheet)
在文件渲染的根级别（例如在 `<SafeAreaView>` 内部最后的 `<Modal>` 旁边），新增一个 Modal 用来展示模型列表。

- 使用半透明黑色背景 `backgroundColor: 'rgba(0,0,0,0.5)'`。
- 底部白底卡片容器：`borderTopLeftRadius`, `borderTopRightRadius` 并设定 `padding`。
- 使用 `<FlatList>` 渲染 `availableModels`，每一项显示 `model.name` 以及可能的 `model.capabilities` (能力标签)。
- 选中某一项时，调用 `setSelectedModelId(model.id)` 并关闭 Modal (`setModelPickerVisible(false)`)。
