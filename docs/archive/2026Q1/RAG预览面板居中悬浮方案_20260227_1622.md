# RAG 引用预览面板移至输入框下方居中显示修改方案

## 🎯 需求目标

当前点击 RAG 引用文档时，预览面板（`RagReferencePreviewPanel`）在桌面端会从最右侧滑出挤占聊天空间，在移动端会全屏弹出。
根据最新需求，我们需要将其改为**在输入大框的下方（或紧贴输入框内部区域底部）居中弹出显示**，不再作为侧边栏或全屏遮罩弹窗。

---

## 🛠️ 给 Codex 的修改指南

请按照以下两步修改 `src/components/chat/ChatInterface.tsx` 实现该需求：

### 第一步：去掉侧边栏和全屏 `<Dialog>` 弹窗的代码

请找到 `ChatInterface.tsx` 文件最后（大约第 1060-1090 行附近），把这部分负责渲染右侧边栏和 Dialog 的包裹代码**完全删除**：

```tsx
      {/* ❌ 删掉原本的右侧边栏 */}
      <div className={cn('hidden md:flex shrink-0 ...', ...)}>
        <RagReferencePreviewPanel ... />
      </div>

      {/* ❌ 删掉移动端的 Dialog 弹窗 */}
      <Dialog open={previewOpen && !!selectedReference} onOpenChange={setPreviewOpen} className="md:hidden">
         ...
      </Dialog>
```

### 第二步：将预览面板转移至输入框容器上方，居中悬浮

找到底部的输入区域容器（包含 `<textarea>` 的那个 `div`，大约在 982 行，有个 `max-w-3xl mx-auto relative...` 的注释），在它的**外围上方**添加预览面板，居中显示且带有滑出动画。

修改后的结构应该如下所示：

```tsx
      {/* 底部输入区域容器 */}
      {/* ✅ 1. 在底部输入区域容器的外围包个相对定位的 div，确保相对底部定位 */}
      <div className="p-4 shrink-0 transition-all duration-300 relative">
        
        {/* ✅ 2. 注入悬浮的 RAG 预览面板（居中、悬浮于输入框上方） */}
        {previewOpen && selectedReference && (
          <div className="absolute bottom-[calc(100%-1rem)] left-1/2 -translate-x-1/2 w-full max-w-3xl px-4 z-50 animate-in slide-in-from-bottom-4 fade-in duration-200">
            <div className="bg-white/90 dark:bg-gray-900/95 backdrop-blur-xl border border-gray-200 dark:border-gray-700 shadow-2xl rounded-2xl overflow-hidden h-[400px]">
              <RagReferencePreviewPanel
                open={previewOpen}
                reference={selectedReference}
                activeTab={activeTab}
                onTabChange={setActiveTab}
                fullContentState={selectedFullContent}
                isFullContentLoading={isFullContentLoading}
                onClose={() => setPreviewOpen(false)}
                className="h-full border-none bg-transparent" /* 去除组件自带的背景和边框，由外层接管 */
              />
            </div>
          </div>
        )}

        {/* 原本的输入大框保持不变 */}
        <div className="max-w-3xl mx-auto relative rounded-2xl bg-white/30 dark:bg-white/5 border border-white/30 dark:border-white/10 shadow-sm backdrop-blur-sm overflow-hidden transition-all duration-300 focus-within:ring-2 focus-within:ring-blue-500/20">
          <textarea
            ref={textareaRef}
            ...
```

### ✨ 修改效果说明：
1. 完全废弃了右侧滑出和移动端全屏弹窗。
2. `bottom-[calc(100%-1rem)]` 控制了面板紧贴在输入框容器内容上方弹出。
3. `left-1/2 -translate-x-1/2 max-w-3xl` 使其与下方的输入框完美对齐并居中。
4. 给了 `h-[400px]` 的固定高度搭配圆角阴影，宛如从输入框生长出来的一个美观的拓展卡片。
