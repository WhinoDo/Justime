## 主要问题分类

### 1. 安全性问题 (P0级)

#### 1.1 已修复的安全问题 ✅
- JWT密钥硬编码问题已修复
- 不安全的默认密钥已移除
- Cookie安全属性已强化
- 生产环境凭据泄露风险已解决

#### 1.2 待解决的安全问题 ⚠️

**问题 #1: 客户端传入userId导致的越权风险**
- **文件：** `justime_agent/src/app/api/calendar/events/route.ts:18`
- **严重程度：** P0 (高危)
- **影响：** 攻击者可以通过修改userId参数访问或修改其他用户的数据
- **建议修复：**
  ```typescript
  // 当前代码（危险）
  const userId = searchParams.get('userId');

  // 建议修改为
  const userId = await getCurrentUserId(request); // 从JWT token获取
  ```

**问题 #2: 缺少输入验证和XSS防护**
- **文件：** 多个API端点
- **严重程度：** P1 (中危)
- **影响：** 可能导致XSS攻击和SQL注入
- **建议修复：**
  - 添加输入验证中间件
  - 使用DOMPurify清理用户输入
  - 实施CSP（内容安全策略）

**问题 #3: API速率限制缺失**
- **文件：** 所有API端点
- **严重程度：** P1 (中危)
- **影响：** 系统容易受到DDoS和暴力破解攻击
- **当前状态：** 已创建rate_limiter.py，但尚未集成
- **建议修复：** 在FastAPI应用中启用速率限制中间件

### 2. 性能问题 (P1级)

#### 2.1 数据库性能

**问题 #4: N+1查询问题**
- **文件：** `justime_backend/app/business/chat_business.py`
- **严重程度：** P1
- **影响：** 数据库查询性能下降，响应时间变慢
- **示例：**
  ```python
  # 当前代码（低效）
  conversations = await Conversation.find().to_list()
  for conv in conversations:
      messages = await Message.find({"conversation_id": conv.id}).to_list()

  # 建议修改为
  conversations = await Conversation.find().to_list()
  conv_ids = [c.id for c in conversations]
  messages = await Message.find({"conversation_id": {"$in": conv_ids}}).to_list()
  ```

**问题 #5: 缺少数据库索引**
- **严重程度：** P1
- **影响：** 查询性能随数据量增长急剧下降
- **当前状态：** 已创建indexes.py，需确认是否已应用
- **建议：**
  - 为user_id、created_at、status等字段添加索引
  - 定期监控慢查询日志

#### 2.2 内存使用

**问题 #6: 大文件上传内存峰值**
- **文件：** `justime_backend/app/api/v1/endpoints/knowledge.py:81`
- **严重程度：** P1
- **影响：** 并发大文件上传时可能导致内存耗尽
- **建议修复：**
  ```python
  # 当前代码（内存密集）
  content = await file.read()  # 一次性读取整个文件

  # 建议修改为流式处理
  async with aiofiles.open(file_path, 'wb') as f:
      while chunk := await file.read(1024 * 1024):  # 1MB chunks
          await f.write(chunk)
  ```

#### 2.3 缓存缺失

**问题 #7: 频繁查询未缓存**
- **文件：** 用户配置、模型配置等高频查询
- **严重程度：** P2
- **影响：** 数据库压力增大，响应时间不稳定
- **建议修复：**
  - 实施Redis缓存策略
  - 对配置数据实施多级缓存
  - 添加缓存失效机制

### 4. 代码质量问题 (P2级)

#### 4.1 错误处理

**问题 #11: 时区处理不一致**
- **文件：** 多处使用`datetime.now()`
- **严重程度：** P1
- **当前状态：** ✅ 已修复为`datetime.now(timezone.utc)`

**问题 #12: 裸except异常捕获**
- **文件：** 多个异常处理块
- **严重程度：** P2
- **影响：** 吞没重要错误，难以调试
- **建议修复：**
  ```python
  # 当前代码（不推荐）
  try:
      ...
  except:
      pass

  # 建议修改为
  try:
      ...
  except SpecificException as e:
      logger.error(f"具体错误信息: {e}", exc_info=True)
  ```

#### 4.2 日志记录

**问题 #13: 使用print而非logging**
- **文件：** 多处业务代码
- **严重程度：** P2
- **当前状态：** ✅ 已修复为使用logging

**问题 #14: console.log调试代码残留**

- **影响：** 可能泄露敏感信息，影响性能
