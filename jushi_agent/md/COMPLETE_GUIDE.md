## 🎯 项目概述

### 产品定位

**「聚时」(JuShi)** 是一款专为大学生设计的情绪-任务双驱动智能助手，通过AI技术帮助用户缓解学业焦虑、提高任务完成效率。

### 核心价值

- **情绪优先**：基于用户情绪状态调整AI交互策略
- **智能拆解**：根据焦虑程度动态调整任务拆解粒度
- **个性化支持**：提供温暖贴心的学习伙伴体验

### 核心机制

```
用户输入 → 情绪评估 → 动态AI策略调整 → 智能任务拆解 → 执行指导 → 反馈优化
```

## ✨ 核心功能

### 1. 智能情绪分析

- **自动情绪识别**：基于AI分析用户文本情绪状态
- **1-10分评分系统**：量化情绪状态
- **情绪标签**：识别具体情绪类型（焦虑、压力、迷茫等）
- **情绪感知增强**：AI先进行情绪安抚，再提供任务规划

### 2. 情绪驱动对话

根据情绪评分调整AI回复策略：

| 评分区间 | 状态描述 | AI策略 | 任务拆解特点 |
|----------|----------|--------|-------------|
| 1-3分 | 重度焦虑 | 极度温和支持 | 原子级步骤，5分钟内完成 |
| 4-6分 | 中度焦虑 | 理解引导 | 流程化拆解，明确时间预估 |
| 7-10分 | 状态良好 | 积极协作 | 目标导向，框架性指导 |

### 3. 智能任务拆解

- **动态策略**：根据情绪评分自动选择拆解策略
- **时间感知**：结合当前时间智能安排任务
- **结构化输出**：生成JSON格式的任务数据

### 4. 现代化聊天界面

- 🎨 全新UI设计，支持深色/浅色主题切换
- 📝 完整Markdown渲染支持（标题、列表、表格、引用等）
- 💻 代码语法高亮，支持多种编程语言
- 📋 一键代码复制功能
- 🚀 流畅动画效果和用户体验优化
- 📱 完美响应式设计，支持移动端和桌面端

### 5. 用户认证系统

- **多种登录方式**：邮箱/用户名密码、飞书账号登录
- **飞书账号绑定**：现有账户可绑定飞书账号
- **安全机制**：JWT令牌、密码加密、登录保护
- **个人信息管理**：完整的用户资料和偏好设置

### 6. 时间感知功能

- **当前时间识别**：AI能够理解当前时间上下文
- **相对时间解析**：支持"明天上午"、"2小时后"等自然语言
- **智能时间建议**：根据时间段提供合适的任务安排建议
- **时间助手组件**：可视化时间选择和任务输入

### 7. 飞书集成

- **OAuth认证**：完整的飞书登录流程
- **日历管理**：获取和同步飞书日历事件
- **账号绑定管理**：支持绑定和解绑飞书账号
- **登出管理**：多种登出方式（简单登出、完全登出、撤销授权）

### 8. 数据持久化

- **MongoDB集成**：用户数据和对话记录完整存储
- **对话历史**：保存所有对话记录和情绪分析数据
- **用户画像**：记录用户偏好和习惯
- **统计信息**：会话数、消息数、Token使用量等

## 🚀 快速开始

### 环境要求

- Node.js 18+
- npm 或 yarn
- MongoDB（本地或云端）

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/你的用户名/jushi-ai-assistant.git
cd jushi-ai-assistant
```

2. **安装依赖**
```bash
npm install
```

3. **配置环境变量**

创建 `.env.local` 文件：
```env
# AI API 配置 (必需)
SILICONFLOW_API_KEY=你的硅基流动API密钥

# Next.js 配置
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-key
NODE_ENV=development

# MongoDB 配置
MONGODB_URI=mongodb://localhost:27017/jushi-agent

# JWT 配置
JWT_SECRET=your-jwt-secret
JWT_REFRESH_SECRET=your-refresh-secret
```

4. **获取API密钥**

- 访问 [硅基流动官网](https://cloud.siliconflow.cn/)
- 注册并登录账户
- 进入 "API 管理" 页面创建API密钥

5. **启动开发服务器**
```bash
npm run dev
```

6. **访问应用**

打开浏览器访问 `http://localhost:3000`

### 测试API连接

```bash
node test-api.js
```

## 🌐 部署指南

### Vercel部署（推荐）

1. **连接GitHub仓库**到Vercel
2. **配置环境变量**：
   - `SILICONFLOW_API_KEY`
   - `NEXTAUTH_URL`
   - `NEXTAUTH_SECRET`
   - `MONGODB_URI`
   - `JWT_SECRET`
   - `JWT_REFRESH_SECRET`
3. **自动部署**：Vercel会自动部署应用

### 其他部署选项

- **Netlify**：适合静态站点和简单API
- **Railway**：支持数据库，容器化部署
- **Render**：免费PostgreSQL数据库

## 🔧 故障排除

### API连接问题

- **401错误**：检查API密钥是否正确配置
- **连接失败**：确认网络连接和API服务状态
- **测试连接**：使用 `node test-api.js` 验证

### 认证问题

- **登录失败**：检查数据库连接和用户数据
- **令牌过期**：自动刷新机制应处理此问题
- **权限错误**：确认用户认证状态

### 数据库问题

- **连接失败**：检查MongoDB连接字符串
- **数据丢失**：确认数据库备份策略
- **性能问题**：检查索引和查询优化
