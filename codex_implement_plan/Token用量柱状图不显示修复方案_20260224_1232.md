# Token 用量柱状图不显示修复方案

> **文件作用**: Token 用量统计柱状图渲染 bug 根因分析与修复方案  
> **创建时间**: 2026-02-24 12:32

---

## Bug 现象

模型配置页面右侧面板中的 Token 用量柱状图区域虽然渲染了容器，但柱状条不可见。

---

## 根因分析

**问题文件**: [page.tsx](file:///Users/zhuyuxuan/Desktop/Code/jushi/jushi_agent/src/app/model-config/page.tsx)

**核心原因**: 柱状图的 CSS 布局导致每根柱条的高度塌缩为 0。

### 问题代码 (第 256 行)

```tsx
<div className="h-28 flex items-end gap-1.5">  // ← 父容器
  {dailyPoints.map((point) => (
    <div className="flex-1 rounded-sm bg-white/5 relative overflow-hidden group">  // ← 柱条容器
      <div
        className="absolute bottom-0 left-0 right-0 rounded-sm bg-indigo-400/80"
        style={{ height: `${barHeight}%` }}  // ← 实际柱条 (百分比高度)
      />
    </div>
  ))}
</div>
```

### CSS 布局解析

```
父容器: h-28 (高度 7rem/112px), flex (默认 flex-row), items-end
  ↓ align-items: flex-end → 子元素不拉伸，按底部对齐
  ↓ 子元素高度 = 内容高度

柱条容器: flex-1, relative, overflow-hidden
  ↓ flex-1 仅影响主轴 (宽度)，不影响交叉轴 (高度)
  ↓ 唯一内容是 position: absolute 的柱条 → 脱离文档流
  ↓ 内容高度 = 0

实际柱条: absolute, height: ${barHeight}%
  ↓ 百分比高度参考父元素 (柱条容器) 的高度
  ↓ 柱条容器高度 = 0
  ↓ 实际柱条高度 = 0% × 0px = 0px ← 不可见！
```

**结论**: `items-end` 阻止子元素拉伸到父容器高度，而子元素内部只有 `position: absolute` 的内容不占用空间，导致子元素高度为 0，柱条百分比高度无参考基准。

---

## 修复方案

### 方案: 为柱条容器添加 `h-full` 显式高度

**修改文件**: `src/app/model-config/page.tsx` 第 260 行

```diff
 <div
   key={`${model.configId}-${point.date}`}
-  className="flex-1 rounded-sm bg-white/5 relative overflow-hidden group"
+  className="flex-1 h-full rounded-sm bg-white/5 relative overflow-hidden group"
 >
```

**原理**: `h-full` 等于 `height: 100%`，使柱条容器显式继承父容器的 `h-28` (112px)。此后 `position: absolute` 的柱条使用 `height: ${barHeight}%` 时有了正确的参考基准（112px），同时 `items-end` 不影响这里，因为 `h-full` 已经显式设定高度。
