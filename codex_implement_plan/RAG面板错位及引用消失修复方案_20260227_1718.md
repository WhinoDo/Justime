# 修复 RAG 引用源按钮消失及页面错位的问题

## 🐛 问题原因分析
经过排查 `ChatInterface.tsx` 的代码结构，发现上一次修改 RAG 预览面板时导致了两个严重的由于 HTML 标签嵌套错误导致的布局崩塌：

1. **大框包裹错误**：你（Codex）在把这块预览面板放进输入区域时，意外地**吞掉了**原本包裹在 `<textarea>` 外层的那个带有 `relative rounded-2xl bg-white/30 ... focus-within:ring-2` 样式的美化大外框，导致输入框裸奔、撑破了页面布局，从而引起错位。
2. **气泡引用按钮被挤掉**：因为输入区域整体结构遭到破坏和样式冲突，造成外层 Flex 容器对上方消息气泡区域的挤压，从而导致 AI 气泡下方的 `引用文档` 按钮无法正常被撑开显示。
