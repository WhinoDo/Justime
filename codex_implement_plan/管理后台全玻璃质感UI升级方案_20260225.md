# 聚时管理后台 - 全局磨砂玻璃（Glassmorphism）UI升级方案

## 1. 升级目标
将当前以纯白（`bg-white`）和浅灰（`bg-gray-50`）为主的传统后台管理系统皮肤，统一升级为与 `Dashboard` (控制台) 完全一致的**黑夜沉浸式磨砂玻璃材质**（Glassmorphism）。
此方案旨在供 `GPT-Codex3` 执行，请严格依据此文档逐步推进，确保各组件不漏掉任何颜色替换。

---

## 2. 核心公共组件替换 (Layout)

**目标文件：** `jushi_agent/src/app/admin/layout.tsx`

### 2.1 引入全局背景组件
在文件头部引入 `JushiBackground`：
```tsx
import { JushiBackground } from '@/components/ui/JushiBackground'
```

### 2.2 替换主容器背景与文本体系
将 `<div className="min-h-screen bg-gray-50 flex">` 替换为带有渐变背景与通用字色的容器：
```tsx
<div className="min-h-screen relative overflow-hidden font-sans flex text-white">
    {/* 注入与 Dashboard 一致的全局背景 */}
    <JushiBackground blur="lg" opacity={0.6} />
    {/* ... 其他内容需要提升 z-index 保证在背景之上 */}
```

### 2.3 侧边栏 (Sidebar) 玻璃化
**原逻辑**：`<aside className="... bg-white border-r border-gray-200 ...">`
**修改为**：
```tsx
<aside className={`fixed inset-y-0 left-0 z-50 w-64 bg-black/20 backdrop-blur-xl border-r border-white/10 transform transition-transform duration-200 ease-in-out ${isSidebarOpen ? 'translate-x-0' : '-translate-x-full'} lg:relative lg:translate-x-0`}>
```
- 修改 Logo 文字颜色为：`text-white drop-shadow-md`
- 修改侧边栏菜单未选中态：`text-white/70 hover:bg-white/10 hover:text-white`
- 修改侧边栏菜单选中态：`bg-white/20 text-white shadow-inner`
- 修改返回控制台与用户 Profile 区域的边框：`border-t border-white/10` 和相关的 `text-gray-*` 为 `text-white/70` 或 `text-white`。

### 2.4 移动端 Header 玻璃化
**原逻辑**：`<div className="lg:hidden h-16 bg-white border-b border-gray-200 ...">`
**修改为**：
```tsx
<div className="lg:hidden h-16 bg-black/20 backdrop-blur-xl border-b border-white/10 flex items-center px-4 relative z-20">
```
确保 Title 颜色为 `text-white`。

## 3. 子页面深度适配 (Pages)

在全面变黑的背景下，所有子页面的原白色卡片、文字全部需要反色与半透明化处理。

### 3.1 概览大盘 (`src/app/admin/page.tsx`)
- **标题体系**：`text-gray-900` 修改为 `text-white`，`text-gray-500` 修改为 `text-white/70`。
- **StatCard 组件**：
  放弃原有包裹的 `<Card>` 默认样式，可以覆写 `Card` 或直接使用玻璃拟态的 `div`：
  ```tsx
  <div className="p-6 rounded-2xl bg-white/10 backdrop-blur-md border border-white/20 shadow-xl transition-all hover:bg-white/20 hover:border-white/30">
      {/* 内容文字需要改为 text-white, 图标 text-white/50 等 */}
  </div>
  ```

### 3.2 用户管理 (`src/app/admin/users/page.tsx`) & 模型管理 (`src/app/admin/models/page.tsx`)
这两个页面结构相似，均包含**顶部搜索/操作区**与**主体数据表格**。

- **标题与副标题**：全部改为暗黑模式（`text-white`, `text-white/70`）。
- **表格容器容器**：
  将原本包裹 `Table` 的 `<div className="rounded-md border bg-white shadow-sm">` 修改为：
  ```tsx
  <div className="rounded-2xl border border-white/20 bg-white/5 backdrop-blur-xl shadow-2xl overflow-hidden text-white w-full">
  ```
- **表头 (TableHeader/Head)**：
  增加轻微的分离感，例如在包裹 TableHeader 的行上应用 `border-b border-white/10 bg-white/5 text-white/80`。
- **表格单元格 (TableCell)**：
  主副标题（例如 Name 和 Email）分别替换为 `text-white` 和 `text-white/60`。
  列表中的 Badge 以及小图标颜色可保留本身色彩体系，但底色可以调整为去饱和度（如 `bg-blue-500/20 text-blue-200` 等）。
- **输入框 (Input)**：
  去掉 `bg-white`，应用 `bg-black/20 border-white/20 text-white placeholder:text-white/50 focus:ring-white/30`。
- **弹窗 (Dialog/DropdownMenu 等)**：
  需要覆写底层 content 材质，比如给 `DialogContent` 加上 `className="bg-gray-900/90 backdrop-blur-xl border-white/20 text-white"`。

##执行标准 💡
请 `GPT-Codex3` 在执行时切记：
1. **不要一键暴利擦除**：保留原始文件内的逻辑流、状态机以及所有绑定的函数 (`handleSubmit`, `handleDelete` 等)。
2. **纯样式替换**：这是一次前端 UI Refactoring。重点针对 `bg-white`、各类 `text-gray-900` 以及各类 `border-gray-200` 进行排查与替换。
3. **连贯一致**：做完这三个页面和布局的替换后，整个后台应该完全融入由 `JushiBackground` 营造出的神秘、深邃且毛玻璃质感的高级审美中。
